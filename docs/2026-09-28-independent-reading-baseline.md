# 真实盘面独立判断：先冻结判断，再修改程序

本文件在本轮引擎修改之前写入。读取的是原始逐分钟价格与前一交易日梯队，未从程序的 core.candidates、leadLag 标签或最终 summary 反推答案。价格来源为 lib/emotion-tracking.generated.json；历史身份来源为 lib/close-history.generated.json。另用本机留存的9月28日原始梯队接口快照复核负反馈。

## 边界

9月18日可见分钟样本74只，9月24日83只，来自既有采集/补录范围，不是全市场全量，不能证明范围外没有更早发动者。历史分钟是事后恢复的精确日期价格，以下是按事件时间截断的价格回放，不冒充当时系统已收到全部数据。当前交易日收盘梯队、最终炸板次数、次日结果、晚于观察日采集的概念关系均不作为早盘判断输入。历史概念不齐不妨碍观察股票价格及同身位比较，但阻止主线/因果断言。

## A：2026-09-18 09:40，同身位分歧

已知昨日：澳弘电子5板；华瓷股份、锡华科技、中晶科技均3板。

独立价格事实：华瓷09:30为+5.53%，09:31触及+10.01%后到09:40所有分钟保持；锡华09:31为+9.98%，09:32回落至+4.52%，09:39为+2.73%，09:40为+3.45%；中晶09:30已在+10.00%，09:36回落+7.73%、09:37为+5.95%，09:40回到+10.00%；澳弘09:40为+0.27%，不在封板状态。

判断：华瓷是本组更稳定的封板承接者；锡华先触板后分歧，不可称被华瓷带动（两者同为09:31触板，先后不足）；中晶已经出现一次打开后回到涨停价的分钟序列，不能只显示“同身位竞争/无分钟”；昨日最高空间澳弘未延续封板，不应因华瓷封住就说整体高位一致强。

应输出：华瓷“同身位稳定封板/相对抗分歧”，锡华“触板后回落/承接分歧”，中晶“打开后回到涨停价（分钟采样）”。不授予任何股票“明确因果龙头”；不因缺概念把可见承接表现变成MISSING。

华瓷仍为+10.01%，09:31至10:00持续在涨停价。锡华09:51为+4.34%、09:52为+6.76%、09:53回到+9.98%，到10:00维持。中晶09:47仍+10.00%，09:48回落+6.68%，09:53为+5.08%，10:00为+3.27%。澳弘10:00为-2.63%。

程序应保留A→B的变化，不可仅按10:00两个封板结果把华瓷、锡华归为同一种强，也不可将曾开板错误命名爆量（无可比量能）。

判断：先导是该可见样本中明显的早期价格进攻者；慧智微的这段拉升晚于先导，可描述为随后出现上涨响应，不能证明被其因果带动。康强本就高开强势并先后冲高回落，不能简单归为被先导带动的跟风。缺少完整概念及容量证据时不确认“主线容量龙头”，但不能因为昨日没有连板身份而完全不报告先导这段进攻。

应输出一个不与已确认核心混合的“盘中新进攻观察”入口，主动先动与随后响应分开核验，不要求先有两日影响记录。

## 修改必须达到的标准

数据状态与观察结果分开：完整比较窗口中“未见响应”是已完成的观察，不是MISSING。全日有缺点不应抹掉一个完整局部窗口，但不能宣称找到了缺失时段之前的“全日首次”。
当前活跃角色、同身位竞争样本、历史身份跟踪分开，保留历史但不把整个历史注册表作为当前风险分母。普通进攻观察不自动成为核心。
用真实案例断言事实、角色差异、时间顺序和禁用结论；不按现有程序标签改独立答案。本轮先保存此基准，再运行旧程序记录差异，最后修改逻辑并比较。
